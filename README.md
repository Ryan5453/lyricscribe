# LyricScribe

> [!WARNING]
> This project is in progress and does not reflect the final results.

## About

LyricScribe is a research project investigating automated music lyric transcription by combining audio source separation with state-of-the-art speech-to-text (STT) models.

## CLI Tool

The project includes a command-line interface for audio transcription and source separation:

```
# Run using UV
uv sync
uv run lyricscribe --help
```
